# B2. Omni-Builder Framework (v4.0) 🚀

> *An ultra-advanced, zero-dependency visual workspace engine for generating high-performance enterprise applications.*

Welcome to **B2. Omni-Builder v4.0**. This is the evolution of manual web construction. We’ve moved past basic HTML/CSS injectors to a fully-featured, studio-grade visual engine.

### 📊 Evolution: Manual v4.0 vs. Legacy Manual Tools

| Feature | 🛠️ Legacy Manual Tools | 🚀 B2. Omni-Builder v4.0 |
| :--- | :--- | :--- |
| **Compiler Engine** | Basic DOM Manipulation | Advanced Omni-Purpose Compiler |
| **Design Controls** | Standard CSS Properties | Granular Pixel-Perfect Sliders |
| **Presets** | None (Manual Setup) | High-Fidelity Themed Presets |
| **Telemetry** | None | Real-time Dashboard + CSV Export |
| **Export System** | Raw Code Copy | ZIP/HTML/Minified Compiler |
| **Interactivity** | Static Elements | Live Chat & Interactive Widgets |

### ✨ Key Features
* **Dynamic Archetype System:** Switch between SaaS, E-Commerce, Blog, and Chat modes instantly.
* **Absolute Granular Customization:** Pixel-level control over spacing, margins, and radii via live editors.
* **Premium Visual Matrix:** Toggle between `Matrix Neon`, `Nordic Frost`, `Luxury Royal`, and `Vibrant Tokyo` themes.
* **Telemetry Data Hub:** Captured leads and transactions are logged locally with timestamped CSV exports.

### 📦 How to Use
1. Clone the repo: `git clone https://github.com/BehradB289/B2-OmniBuilder.git`
2. Open `b2-omni-builder.html` in any browser.
3. Select your archetype and style preset.
4. Customize via double-click and grid managers.
5. Click **COMPILE & DEPLOY** to finalize your project!
