# B2. Omni-Builder Framework (v4.0) 🚀

> *An ultra-advanced, zero-dependency visual workspace engine for generating high-performance enterprise applications and adaptive layouts.*

Welcome to **B2. Omni-Builder v4.0**, an elite manual design studio and low-code framework engineered to deliver absolute visual customization. Say goodbye to general LLM approximations—this compiler lets you craft, edit, and fine-tune your enterprise web applications with pixel-perfect control.

---

### 📊 Comprehensive Comparison: Manual Edition vs. AI Agent Version

To understand the evolution of the B2 ecosystem, here is how the new **Manual Edition (v4.0)** compares directly with the older **AI Python & Gemini Agent Version (`B2-Hybrid-Web-Builder`)**:

| Feature / Aspect | 🤖 Old Version (AI Python & Gemini Agent) | 🛠️ New Version (B2. Omni-Builder v4.0 Manual) |
| :--- | :--- | :--- |
| **Primary Workflow** | Automated Text-to-Webpage Generation | Absolute Pixel-Perfect Visual Designing |
| **Control Level** | Approximated (AI interprets prompts) | Absolute Granular Element-Level Mutation |
| **Prerequisites** | Python, PIP packages, and Google Gemini API Key | **Zero-Dependency** (Runs directly in the browser) |
| **Execution Sandbox** | Server/Local Terminal Execution required | Instant client-side execution via `srcdoc` iframe |
| **Customization Depth** | Regerating prompt required for major tweaks | Pixels, Padding, Margins, and Corner Radii input sliders |
| **Design Tokens** | Randomized by LLM interpretations | Curated High-Fidelity Themes (Matrix Neon, Nordic Frost, etc.) |
| **Grid Systems** | Predefined card layouts | Multi-Column Responsive Row Managers & Grid Spawners |
| **Interactive Logic** | Static HTML generated content | Active Live Chat Simulator, Deep Sliding Cart Sidebar |
| **Telemetry & Leads** | Simple text file/db saving via Python | Dashboard Matrix UI inside Builder with active CSV Exports |
| **Export Formats** | Single raw generated HTML output | Monolithic HTML Wrapper, Clipboard Code, and Modular ZIP Packages |

### ✨ Key Features

* **Dynamic Website Archetype System:** Seamlessly swap behaviors between **SaaS Product Landing**, **E-Commerce Grid**, **Tech Media/Blog**, and **AI Chat Assistant Mode** (with simulated real-time responsive chat widget).
* **Absolute Granular Customization:** Double-click any text inside the preview to edit inline. Change spacing, margins, padding, and corner radii down to the exact pixel.
* **Premium Visual Presets Matrix:** Toggle high-fidelity styling tokens instantly:
  * `Matrix Neon Cyber` (Crimson and cyan glows over obsidian black)
  * `Nordic Frost Minimal` (Cold ice-blue and clean slates)
  * `Luxury Royal Gold` (Midnight obsidian with majestic gold elements)
  * `Vibrant Tokyo Synth` (Electric purples and toxic neon lime)
* **Custom Responsive Grid Engines:** Build structured grids, embed videos (with aspect-ratio controls), customize blockquotes, and organize columns.
* **Telemetry Data Hub:** Captured leads and simulated transactions are beautifully logged in a local dashboard with timestamped CSV exports.
* **Triple Expandable Compiler:** Output your work as a monolithic single-file production HTML document, clipboard minified source, or a structured ZIP package.

### 📦 How to Use

1. Clone this repository:
   ```bash
   git clone [https://github.com/BehradB289/B2-OmniBuilder.git](https://github.com/BehradB289/B2-OmniBuilder.git)
   ```
2. Open the compiled `b2-omni-builder.html` in any web browser.
3. Choose your preferred archetype and theme preset.
4. Customize layouts, edit grid systems, and double-click texts to modify.
5. Click **COMPILE & DEPLOY** to download your ready-to-host website!
