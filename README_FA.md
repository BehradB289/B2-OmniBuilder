# سیستم مدیریت و بازیساز بصری B2. Omni-Builder (نسخه ۴.۰) 🚀

> *یک موتور فضای کاری بصری فوق‌پیشرفته و بدون وابستگی (Zero-Dependency) برای ساخت اپلیکیشن‌های اینترپرایز با کارایی بالا و صفحات واکنش‌گرا.*

به **B2. Omni-Builder v4.0** خوش آمدید؛ یک استودیوی طراحی دستی نوین و فریم‌ورک لوکد (Low-Code) مهندسی شده برای ارائه شخصی‌سازی‌های بصری مطلق. با طرح‌های تقریبی و نامفهوم مدل‌های زبانی خداحافظی کنید—این کامپایلر به شما امکان می‌دهد با کنترل پیکسلی بی‌نقص، اپلیکیشن‌های تحت وب خود را بسازید، ویرایش و بهینه‌سازی کنید.

---

### 📊 جدول مقایسه جامع: نسخه دستی جدید در مقابل نسخه پایتونی قدیمی

برای درک بهتر تفاوت‌های بنیادی اکوسیستم توسعه B2، جدول زیر مقایسه مستقیمی بین **نسخه دستی جدید (v4.0)** و **نسخه هوش مصنوعی قدیمی پایتون (`B2-Hybrid-Web-Builder`)** ارائه می‌دهد:

| ویژگی / جنبه فنی | 🤖 نسخه قدیمی (AI پایتون و جمینی) | 🛠️ نسخه جدید دستی (B2. Omni-Builder v4.0) |
| :--- | :--- | :--- |
| **روند کار اصلی** | تولید خودکار وب‌سایت از روی توصیف متنی | طراحی بصری با کنترل پیکسلی و دستی مطلق |
| **میزان کنترل روی جزئیات** | تقریبی (تفسیر هوش مصنوعی از متن ورودی) | شخصی‌سازی میلی‌متری و پیکسلی تک‌تک المان‌ها |
| **پیش‌نیازها و راه‌اندازی** | پایتون، کتابخانه‌ها و کلید اختصاصی Gemini API | **بدون نیاز به هیچ پیش‌نیاز** (اجرا مستقیم در مرورگر) |
| **محیط اجرا** | نیاز به اجرای ترمینال محلی یا سرور پایتون | اجرای آنی در سمت کلاینت با ای‌فریم مستقل |
| **شخصی‌سازی فاصله‌ها** | نیاز به نوشتن پرامپت جدید برای تغییر فاصله‌ها | اسلایدرهای اختصاصی مارجین، پدینگ و شعاع انحنا |
| **تم‌ها و ظاهر گرافیکی** | تصادفی بر اساس کدهای خروجی مدل زبانی | قالب‌های لوکس مهندسی‌شده (ماتریکس نئون، نوردیك و...) |
| **سیستم گرید و چیدمان** | چیدمان‌های ساده کارت‌محور | سیستم مدیریت چندستونه، گرید ریسپانسیو و ویدیو پلیر |
| **ویژگی‌های تعاملی** | کدهای استاتیک و غیرفعال | چت‌بات هوش مصنوعی فعال و سبد خرید متحرک واقعی |
| **سیستم ثبت دیتای فرم‌ها** | ذخیره ساده متنی از روی پردازش هوش مصنوعی | داشبورد مدیریت تلمتری با خروجی اکسل (CSV) |
| **نوع فایل‌های خروجی** | یک فایل تک‌ستونی ساده HTML | فایل منفرد بهینه، کپی در کلیپ‌بورد یا پکیج ساختاریافته ZIP |

### ✨ ویژگی‌های کلیدی

* **سیستم آرکتایپ چندمنظوره دینامیک:** تغییر آنی رفتار و اجزای سایت بین حالت‌های **پلتفرم SaaS**، **فروشگاهی پیشرفته (E-Commerce)**، **وبلاگ فناوری و رسانه**، و **چت‌بات هوش مصنوعی پویا** (به همراه ویجت چت زنده تعاملی).
* **شخصی‌سازی مطلق پیکسلی:** قابلیت ویرایش مستقیم و درلحظه تمام متون داخل پیش‌نمایش با دبل‌کلیک. کنترل میلی‌متری فاصله‌های بیرونی (Margin)، فاصله‌های داخلی (Padding) و انحنای مرزها (Corner Radii).
* **پالت‌های بصری لوکس و آماده:** تغییر آنی استایل کلی سایت با یک کلیک روی قالب‌های پریمیوم:
  * `Matrix Neon Cyber` (درخشش نئون صورتی و سایان بر روی پس‌زمینه مشکی مطلق)
  * `Nordic Frost Minimal` (ترکیب سرد رنگ‌های خاکستری ملایم و آبی یخی)
  * `Luxury Royal Gold` (کنتراست باشکوه مشکی ابسیدین و طلایی سلطنتی)
  * `Vibrant Tokyo Synth` (بنفش الکتریکی و رنگ لیمویی نئون متالیک)
* **سیستم گرید منعطف و ماژولار:** امکان ساخت ردیف‌های چندستونه دینامیک، بارگذاری ویدیوها با حفظ ابعاد واکنش‌گرا، افزودن نقل‌قول‌های متالیک و آیکون‌های شبکه تلمتری.
* **داشبورد تلمتری و جذب لید:** ذخیره‌سازی خودکار اطلاعات فرم‌ها و خریدهای شبیه‌سازی‌شده در مرورگر با قابلیت خروجی مستقیم فایل دیتای استاندارد اکسل (CSV).
* **خروجی سه‌گانه و پیشرفته:** کامپایل و دانلود پروژه در قالب فایل منفرد HTML، کپی سریع کد منبع فشرده، یا پکیج ساختاریافته ZIP (تفکیک اصولی فایل‌های HTML، CSS و JS).
