# سیستم مدیریت و بازیساز بصری B2. Omni-Builder (نسخه ۴.۰) 🚀

> *یک موتور فضای کاری بصری فوق‌پیشرفته و بدون وابستگی (Zero-Dependency) برای ساخت اپلیکیشن‌های اینترپرایز.*

به **B2. Omni-Builder v4.0** خوش آمدید. این نسخه تکامل‌یافته‌ای از پروژه‌های دستی قبلی است. ما از ابزارهای ساده تزریق کد، به یک استودیوی طراحی بصری تمام‌عیار رسیده‌ایم.

### 📊 مقایسه: نسخه v4.0 در مقابل ابزارهای دستی قدیمی

| ویژگی | 🛠️ ابزارهای دستی قدیمی | 🚀 نسخه B2. Omni-Builder v4.0 |
| :--- | :--- | :--- |
| **موتور کامپایلر** | دستکاری ساده DOM | کامپایلر پیشرفته Omni-Purpose |
| **کنترل طراحی** | ویژگی‌های استاندارد CSS | اسلایدرهای پیکسلی میلی‌متری |
| **تم‌های آماده** | ندارد (تنظیم دستی) | تم‌های مهندسی‌شده با کیفیت بالا |
| **سیستم تلمتری** | ندارد | داشبورد مدیریت + خروجی CSV |
| **خروجی نهایی** | کپی کد خام | ZIP / HTML / کدهای فشرده |
| **تعامل کاربر** | المان‌های ایستا | چت‌بات زنده + ویجت‌های تعاملی |

### ✨ ویژگی‌های کلیدی
* **سیستم آرکتایپ دینامیک:** تغییر آنی بین حالت‌های SaaS، فروشگاهی، وبلاگ و چت‌بات.
* **شخصی‌سازی پیکسلی:** کنترل کامل روی فاصله‌ها، مارجین‌ها و گوشه‌ها.
* **پالت‌های بصری لوکس:** دسترسی به تم‌های حرفه‌ای مثل نئون، نوردیك، طلایی سلطنتی و...
* **داشبورد تلمتری:** ثبت خودکار لیدها و تراکنش‌ها با قابلیت خروجی اکسل.

### 📦 نحوه اجرا
۱. پروژه را کلون کنید: `git clone https://github.com/BehradB289/B2-OmniBuilder.git`
۲. فایل `b2-omni-builder.html` را در مرورگر باز کنید.
۳. آرکتایپ و تم موردنظر را انتخاب کنید.
۴. با دبل‌کلیک المان‌ها را شخصی‌سازی کنید.
۵. دکمه **COMPILE & DEPLOY** را برای خروجی نهایی بزنید!
